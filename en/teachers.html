Teacher area

A 50-minute lesson plan and an exercise sheet for each volume, ready to print.

How to use it

  • Each lesson plan has objectives, a question to open the class, suggested reading, discussion questions, an interactive activity and a wrap-up.
  • The exercise sheet has multiple-choice questions, with the answer key on a separate page.
  • Use the Print or save as PDF button on each lesson plan. The “For kids” layers help you adapt it for younger classes.
  • To practice debating in class, project the debate simulator and vote as a class.
