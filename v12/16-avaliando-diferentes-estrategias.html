Antes de ler camada de estudo, não faz parte do texto original

Para avaliar estratégias, podemos usar metacritérios: atacar causas, prevenir retrocessos, quanto já foi tentada, histórico, quantos animais beneficia, quanto beneficia cada um, potencial de facilitar mudanças, riscos, custo-benefício, aceitação, alinhamento com outras metas, facilidade e expectativa de sucesso.

Antes de escolher como ajudar, dá para fazer uma lista de perguntas: isso resolve a causa? Ajuda muitos? Pode dar errado? É fácil? Quem já tentou? As respostas ajudam a escolher melhor.

Antes de comprar um carro, comparamos preço, consumo, segurança e manutenção. Estratégias também podem ser comparadas por critérios.

  1. P1 Estratégias diferentes podem ser comparadas por vários metacritérios.
  2. P2 Resta investigar quais critérios incluir, se é possível um resultado geral e que peso dar a cada um.
  3. P3 Também é preciso obter dados objetivos para pontuar as estratégias.
  4. C Logo, a avaliação de estratégias é um campo em aberto, com um roteiro de pesquisa.

Forma lógica do argumento central do capítulo. Se as premissas forem verdadeiras, a conclusão se segue. Para discordar, é preciso mostrar qual premissa é falsa.

Existem metacritérios que poderiam ser utilizados para avaliar diferentes estratégias64? Com base na fundamentação teórica que vimos no capítulo 9, podemos derivar alguns metacritérios. Por exemplo, podemos sempre perguntar, para cada estratégia:

  • Ela ataca a causa do problema ou somente seus sintomas?
  • Qual o seu potencial de prevenir risco de retrocessos?
  • O quão muito/pouco já foi tentada?
  • Se já foi tentada, qual seu histórico de implementação?
  • Quantos animais ela potencialmente beneficiaria?
  • O quanto cada animal afetado seria beneficiado?
  • Qual seu potencial para facilitar mudanças posteriores?
  • Qual o tamanho do risco de desdobramentos negativos?
  • Qual seu custo/benefício?
  • Corre o risco de produzir ganhos baixos ou mesmo nenhum?
  • Qual o tamanho do saldo positivo esperável ao longo do tempo.
  • Potencial de aceitação/rejeição.
  • Qual seu grau de alinhamento/conflito com outras metas?
  • Facilidade/dificuldade de implementação
  • Qual o grau de expectativa quanto ao seu sucesso?
  • Para obter sucesso, depende de outras estratégias serem efetivadas?

Alguns desafios para desenvolvimentos posteriores seriam os seguintes:

(1) Teria de ser investigado se todos os parâmetros acima deveriam ser incluídos ou não, e se há outros parâmetros importantes que deveriam ser acrescentados à lista acima.

(2) Teria de ser investigado se é possível oferecer um resultado geral, em termos do quão mais/menos promissora uma estratégia é em relação à outra, levando em conta todos os parâmetros em conjunto, ou se é possível fazer tal avaliação apenas em relação a cada

parâmetro separadamente, não sendo possível comensurá-los.

(3) Caso se almeje produzir uma comparação geral comensurando os diversos parâmetros, teria de ser investigado se todos os parâmetros devem ter o mesmo peso, ou se há alguns que deveriam pesar mais do que outros (e, em caso positivo, qual deveria ser o peso relativo uns aos outros). Também teria de ser investigado se esse peso seria fixo ou variável e, caso for variável, de que modo deveria variar65.

(4) Investigar a possibilidade de obtenção de dados objetivos em relação à pontuação de cada tipo de estratégia em relação a cada parâmetro.
